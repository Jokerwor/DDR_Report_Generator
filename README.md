## ▶️ Getting Started

Clone the repository

```bash
git clone https://github.com/Jokerwor/Data-Science.git
```

Move into the project directory

```bash
cd Data-Science
```

Install required packages

```bash
pip install numpy pandas matplotlib flask pymongo jupyter
```

Run notebooks using

```bash
jupyter notebook
```
